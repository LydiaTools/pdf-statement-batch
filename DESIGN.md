# PDF Statement Batch / 对账单合表

The user is reviewing extracted transactions, not shopping for a converter. The main view starts with file selection and a batch action, followed by a file ledger and an editable transaction sheet. No marketing hero inside the tool.

- Palette: paper #ffffff, desk #edf2f7, ink #172c42, cobalt #2457c5, success #176a50, caution #946016.
- Type: system humanist sans for controls and body; tabular figures for amounts. No remote font request.
- Layout: a compact left rail holds workspace, settings, then appearance; the file ledger sits beside the active transaction sheet. On narrow screens the ledger precedes the sheet. Amount columns align right; descriptions have room to wrap.
- Characteristic element: a numbered file ledger with a continuous status column. It accounts for every file and makes the source of the selected rows visible.
- Critique before implementation: removed a proposed oversized headline, decorative metric cards and a generic drop-zone hero. Kept the ledger because status, review and omissions are the actual problem. Borders separate records rather than create identical cards.

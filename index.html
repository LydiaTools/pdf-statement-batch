    Processing and privacy

    PDFs are processed in this browser, without an upload or AI request. First use downloads the Python runtime and PDF library. Your batch stays in this tab and is cleared when it closes.

    Text-based PDFs only. Scans need OCR elsewhere; password-protected files must be unlocked first. Extraction can miss or misread rows. Files with different columns or unconfirmed currencies are kept in separate sheets.

    Source references identify the file and extracted row order, not an exact PDF page. Excel includes every file status, even when no transactions were extracted.
